# Plant Greenhouse

Plant Tracker is a web application for managing a personal collection of plants and succulents. Users can add plants, track their care information, record watering events, update plant health, mark favorites, edit plant details, and remove plants from the collection.

## Features

- Add plants to your greenhouse collection
- Track plant species, location, sunlight needs, and watering frequency
- Record the date a plant was last watered
- Track the total number of watering events
- Mark plants as favorites
- Update plant health status
- Add and edit health notes
- Edit a plant's location and last watered date
- Delete plants from the collection

## Tech Stack

- **HTML5:** Application structure and forms
- **CSS3:** Layout and styling
- **JavaScript (ES6+):** Browser interactions and API requests
- **Node.js:** Runtime environment
- **Express:** Web server and application routes
- **MongoDB:** Plant data storage
- **EJS:** Server-side page rendering

## How to Run Locally

Before running the project locally, make sure you have:

- Node.js installed
- A MongoDB Atlas account and database, or a local MongoDB server
- MongoDB network access configured for your development machine
